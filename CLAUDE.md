# Monsieur.meteo — vidéos météo

## Où ranger les vidéos

- **Toutes les vidéos finales vont dans `Vidéo Météo Claude/`** à la racine du dépôt (demande du propriétaire du compte). Ne pas les laisser seulement dans `videos/<projet>/renders/`.
- Nom du fichier : `AAAA-MM-JJ Sujet.mp4` (date de publication prévue), par exemple `2026-10-23 Tempête Boelo.mp4`.
- Mettre à côté la description TikTok prête à coller : `AAAA-MM-JJ Sujet - description.txt`.
- Les sources du projet (script, storyboard, code, audio) restent dans `videos/<projet>/`.
